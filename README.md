# Medical Chatbot

A static, browser-based medical chatbot powered by the Groq API.

## Run locally

```bash
python test.py
```

Then open:

```text
http://localhost:8000
```

## GitHub Pages deployment

This project is designed for static hosting. To publish it on GitHub Pages:

1. Create a public repository named `Nisargaps14.github.io` for your profile site.
2. Push this project to the `main` branch.
3. In GitHub, open the repository > Settings > Pages.
4. Select the `main` branch and the root folder `/`.
5. Save.

Your site will be available at:

```text
https://nisargaps14.github.io/
```

## Notes

- Enter your Groq API key in the chatbot UI.
- The app only responds to medical and health-related questions.
- Voice input/output works in supported browsers.
